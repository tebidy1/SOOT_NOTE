# Channel Permissions Guide

## صلاحيات إدارة القنوات

تم إعداد نظام صلاحيات كامل لإدارة القنوات بناءً على دور المستخدم.

## الأدوار والصلاحيات

### 1. Admin (المدير)
- ✅ يمكنه إنشاء قنوات في أي شركة
- ✅ يمكنه عرض جميع القنوات
- ✅ يمكنه تحديث أي قناة
- ✅ يمكنه حذف أي قناة
- ✅ يمكنه إضافة/إزالة أعضاء من أي قناة

### 2. Company Manager (مدير الشركة)
- ✅ يمكنه إنشاء قنوات في شركته فقط
- ✅ يمكنه عرض قنوات شركته فقط
- ✅ يمكنه تحديث قنوات شركته فقط
- ✅ يمكنه حذف قنوات شركته فقط
- ✅ يمكنه إضافة/إزالة أعضاء من قنوات شركته فقط

### 3. Member (عضو)
- ✅ يمكنه عرض القنوات التي هو عضو فيها
- ❌ لا يمكنه إنشاء قنوات
- ❌ لا يمكنه تحديث القنوات (إلا إذا كان هو منشئها)
- ❌ لا يمكنه حذف القنوات (إلا إذا كان هو منشئها)
- ❌ لا يمكنه إضافة/إزالة أعضاء (إلا إذا كان هو منشئ القناة)

## API Endpoints

### إنشاء قناة
```
POST /api/channels
```
- **Admin**: يجب إرسال `company_id`
- **Company Manager**: `company_id` اختياري (سيتم استخدام شركته تلقائياً)

### عرض قناة
```
GET /api/channels/{id}
```
- **Admin**: يمكنه عرض أي قناة
- **Company Manager**: يمكنه عرض قنوات شركته فقط
- **Member**: يمكنه عرض القنوات التي هو عضو فيها

### تحديث قناة
```
PUT /api/channels/{id}
```
- **Admin**: يمكنه تحديث أي قناة
- **Company Manager**: يمكنه تحديث قنوات شركته فقط
- **Member**: يمكنه تحديث القنوات التي أنشأها فقط

### حذف قناة
```
DELETE /api/channels/{id}
```
- **Admin**: يمكنه حذف أي قناة
- **Company Manager**: يمكنه حذف قنوات شركته فقط
- **Member**: يمكنه حذف القنوات التي أنشأها فقط

### إضافة عضو
```
POST /api/channels/{id}/members
Body: { "user_id": 1 }
```
- **Admin**: يمكنه إضافة أعضاء لأي قناة
- **Company Manager**: يمكنه إضافة أعضاء لقنوات شركته فقط
- **Member**: يمكنه إضافة أعضاء للقنوات التي أنشأها فقط

### إزالة عضو
```
DELETE /api/channels/{id}/members/{userId}
```
- **Admin**: يمكنه إزالة أعضاء من أي قناة
- **Company Manager**: يمكنه إزالة أعضاء من قنوات شركته فقط
- **Member**: يمكنه إزالة أعضاء من القنوات التي أنشأها فقط

## أمثلة

### إنشاء قناة كـ Company Manager
```json
POST /api/channels
{
  "name": "General",
  "description": "General discussion channel",
  "is_private": false
  // company_id سيتم تعيينه تلقائياً لشركة المستخدم
}
```

### إنشاء قناة كـ Admin
```json
POST /api/channels
{
  "name": "General",
  "description": "General discussion channel",
  "is_private": false,
  "company_id": 3  // مطلوب للـ Admin
}
```

## ملاحظات

- جميع الصلاحيات يتم التحقق منها تلقائياً عبر Laravel Policies
- رسائل الخطأ واضحة ومفصلة عند محاولة الوصول غير المصرح به
- Company Manager يرى فقط قنوات شركته في قائمة القنوات
